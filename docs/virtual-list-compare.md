# 虚拟列表对比（简历/面试材料）

长助手回复按行拆分。右侧「虚拟列表对比」面板会实时显示：

| 指标 | 全量渲染 | 虚拟列表 |
|------|----------|----------|
| 挂载节点 | ≈ 总行数（可到几百～上千） | 视口 + overscan，通常几十 |
| 滚动体感 | 长内容时更容易掉帧 | 节点恒定，滚动更稳 |
| FPS | 面板显示当前页面 rAF FPS，可在开关两种模式后对比 | 同左 |

> 面板默认收起；桌面顶栏点「虚拟列表对比」打开。窄屏为省空间隐藏该入口（仍默认启用虚拟列表）。

## 怎么截一张对比图（阶段 C 清单）

1. 桌面浏览器打开生活助理 Agent，新建会话，发送任意一句话，等回复流完（演示模式也有长文）。
2. 点「虚拟列表对比」，保持「启用虚拟列表」，记下「总行数 / 挂载节点 / FPS」，滚动消息区截图。
3. 关掉「启用虚拟列表」，再滚动一次，挂载节点应接近总行数；再截一张。
4. （可选）生成中点「中断」→ 半截 + `cancelled`；再「重试」——另截一张讲状态机。
5. 两张（或三张）图放进简历项目说明或 GitHub README。

话术详见 [面试话术.md](./面试话术.md)。

## 和对话链路相关的工程点

- **状态不串**：`connecting → generating → completed | failed | cancelled`，取消/失败的半截内容保留，但不会落成 `completed`。
- **重连去重**：每个 chunk 带单调 `seq`；前端 `lastSeq` 丢弃重复；断线用 `from_seq` / `Last-Event-ID` 续传。
- **同一条消息只挂一次**：流式只改 `content`，不按 chunk 追加 DOM 气泡。
