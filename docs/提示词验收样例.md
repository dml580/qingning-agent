# 文书模版提示词验收（电子文本即可，无需纸质）

**说明：** 下列均为**虚构**合同/通知，仅用于本地测提示词。配好 API Key 后跑真模型；演示模式只能看流程，不能验准确率。

文档分两套难度：

| 套别 | 用途 | 特点 |
|------|------|------|
| **A · 短样例** | 冒烟、快速回归 | 条款直白，坑一眼能见 |
| **B · 复杂长文** | 逼近真实文书 | 条款更长、定义绕、交叉引用、大写金额，坑埋在正文里 |

## 怎么算「过关」

每条回复人工打勾（不必打分）：

1. **结构完整**：有摘要、关键信息、风险点、建议确认、免责（格式大致符合即可）  
2. **数字不编造**：金额、日期、比例须能在原文找到；没有的应写「原文未写清」  
3. **模版对症**：能点到该模版最该盯的坑（见各节「应抓到」）  
4. **不过度承诺**：不说「一定能退 / 一定违法 / 一定胜诉」  
5. **风险可核对**：列出的风险能对应到原文某句  

任一条严重编造数字或漏掉「应抓到」里的硬坑 → 记失败，再改 `server/catalog.py` 后重测。

# 套 A · 短样例（冒烟）

## A1. 通用要点

**应抓到：** 自动续约、单方改价、提前解约违约金、管辖地。

```
【虚构】软件订阅服务协议（摘要）

甲方：青果科技有限公司
乙方：用户（个人）

1. 服务期：自开通之日起 12 个月。到期前 15 日乙方未书面提出不续约的，自动续约 12 个月。
2. 费用：首年 598 元/年，续约价格以甲方届时官网公示为准，甲方可提前 7 日公告调整。
3. 付款：开通时一次性支付；续约费在到期日前自动从绑定账户扣划。
4. 解约：服务期内乙方提前解约，已支付费用不予退还，并须支付剩余服务期费用的 30% 作为违约金。
5. 争议：提交甲方所在地人民法院管辖。
```

## A2. 租房合同

**应抓到：** 押金 2 个月及扣款条件含糊、涨租、提前退租违约金、维修责任。

```
【虚构】房屋租赁合同（节选）

出租人：张某；承租人：李某
房屋：本市示例路 88 号 601 室

1. 租期：2026 年 3 月 1 日至 2027 年 2 月 28 日。
2. 租金：每月 4500 元，每月 5 日前支付；逾期按日支付租金 0.5% 的滞纳金。
3. 押金：两个月租金即 9000 元。退租时若房屋及设施有损坏、清洁不达标或欠费，出租人有权从押金中扣除，余款于退房后 15 日内退还。
4. 涨租：租期满后若续租，租金上浮不超过 10%，具体以出租人书面通知为准。
5. 提前退租：承租人提前解除合同的，押金不予退还，并赔偿一个月租金。
6. 维修：房屋主体结构由出租人负责；日常损耗及水电燃气等由承租人负责。
7. 转租：未经出租人书面同意不得转租。
```

# 套 B · 复杂长文（绕弯 / 交叉引用）

**设计意图：** 用更正式的体例（定义条款、大写金额、「以附件/届时协议为准」、自动续展与扣款分条写），避免短样例那种「标题里就写零利息」的直球。复制整段到**对应模版**发送。

**应抓到**与套 A 相同；额外观察：是否仍能从长文里抠出硬坑，且不把「未写清」的东西算死。
