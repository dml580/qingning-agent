## 四、想做的功能（未开工）— 多模型自选接入

**目标：**  
用户在页面上自己选择 / 配置要接入的大模型 API，并在界面上清楚显示「当前用的是哪个模型」（类似现在顶栏显示豆包）。

**期望体验（草稿）：**

1. 设置里可选提供商，例如：豆包（火山方舟）、通义、DeepSeek、硅基流动、自定义 OpenAI 兼容等  
2. 填写：API Key、Base URL（可选）、Model ID  
3. 顶栏 / 徽章实时显示：`提供商 · 模型名`（现在已有豆包徽章，可扩展）  
4. 切换模型后，新消息走新配置；旧会话是否绑定当时模型可再定  
5. Key **不要**写进前端仓库；优先「仅存本机 / 后端加密或环境变量」，演示版可「仅当前浏览器 session、不落盘」并醒目标注风险  

**实现时注意：**

- 后端已是「LLM 适配一层」思路（`server/llm.py`），适合扩成多 provider  
- 与 `catalog` 文书模版正交：模版管提示词，设置管模型通道  
- 隐私：用户自填 Key 时要提示「Key 存在哪、会不会上传到你的服务器」

**状态：** 想法已记录，尚未设计 UI / 接口。
