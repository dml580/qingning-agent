# AI 前端 · 演示检查清单（约 3 分钟）

**项目一句话（简历可用）：**  
独立完成「青柠」生活助理 Agent 前端：React+TS 实现 SSE 流式对话、消息状态机与断线续传，含模版隔离会话、长回复虚拟列表、可选迷你 RAG（切块检索+出处标注）与多模型可插拔联调。

---

## 开场（15 秒）

1. 打开站点，点明技术栈：**React + TypeScript + Vite**，后端 FastAPI SSE。  
2. 指一下顶栏：**流状态 pill**、模版条、主题切换（可选一句）。

## 主路径（约 90 秒）

1. 选一个文书模版（如「租房」）→ 粘贴短样例 → **发送**。  
2. 指给面试官看：  
   - 气泡状态：`连接中` → `生成中` → `完成`  
   - 正文**边出边滚**（吸底）；手动上滑后不再强拖  
3. 生成中点 **中断** → 半截保留，状态 **已取消**（不是 completed）→ 点 **重试**。  
4. 切换另一个模版 → 说明 **一模版一会话**，历史不混。

## 工程亮点（约 60 秒）

1. 打开 **虚拟列表对比**（长回复时）：关/开虚拟列表，看挂载节点 / FPS。  
2. 一句话讲 **seq 去重 + from_seq 续传**（防重复 chunk）。  
3. （加分）粘贴长合同：口述后端做了迷你 RAG（默认开启、短文自动跳过）；气泡显示「已引用原文 N 段」。  
4. （可选）模型设置：Key 只在本机后端；通道与提示词模版解耦。

## 收尾（15 秒）

- 复制全文 / 导出 Markdown；失败态有明确文案与重试。  
- 问面试官要不要看代码路径：`MessageArea` / `useSseStream` / `AgentContext`。

---

## 口述速查

| 问题 | 答法 |
|------|------|
| 为什么要状态机？ | 避免断线/取消后把半截当成成功；终态与 content 分离 |
| 为什么要 seq？ | 重连回放会重复；按序号幂等拼接 |
| 虚拟列表？ | 长文按行只挂视口附近节点；流式中不切虚拟，防闪动 |

详细话术见 `docs/面试话术.md`。
