# 浏览器兼容（阶段 C）

## 目标环境

| 浏览器 | 建议版本 |
|--------|----------|
| Chrome / Edge | 近两年稳定版（约 100+） |
| Firefox | 近两年稳定版 |
| Safari | macOS / iOS 近两年版本 |

手机浏览器可完成「选模版 → 发送 → 看流式结果」，复杂对比（虚拟列表面板）以桌面为准。

## 依赖的能力

- `fetch`、ES modules、CSS 变量  
- `EventSource`（SSE 流式；缺了则无法真推流）  
- 现代布局：`flex` / `grid`；配色使用 `color-mix`（不支持时样式变朴素，功能仍可用）

## 产品内降级

启动后若探测到明显缺口，页顶会出现可关闭的「浏览器兼容提示」（`CompatBanner`）。  
不会强行阻断使用，但流式或样式可能异常——提示用户换新版桌面浏览器。

## 不做的范围

- 不兼容 IE  
- 不为极旧安卓 WebView 单独打补丁  
- 公网多端矩阵测试可在部署后再补
